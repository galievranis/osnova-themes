# Osnova Themes

Запуск: `npm run dev`, затем http://localhost:5173.

В корне платформы — редактор. Четыре исходных экрана доступны в предпросмотре и отдельно: `/feed.html`, `/blog.html`, `/post.html`, `/popover-profile.html`. Отсутствующие экраны ведут на локальную страницу.

Создайте копию темы кнопкой «+», переименуйте, настройте светлую и тёмную палитры. Изменения сохраняются в браузере. CSS содержит обе схемы и базовые серые токены; JSON можно импортировать для продолжения работы.

`npm run build` собирает статические файлы в `dist/`.

Оригинальные MHTML не меняются. Восстановление рабочих страниц (перезаписывает HTML): `python3 scripts/restore_html.py`, затем `python3 scripts/prepare_feed.py` и `python3 scripts/make_responsive.py`. Требуются Python и beautifulsoup4. Локальные фотографии в placeholders извлечены из архивов.

Оригинальный production JavaScript отключён. Это локальный просмотр сохранённых экранов, без серверных действий и авторизации. Несохранённые в MHTML шрифты заменяются системным шрифтом.
