# Osnova Themes

Запуск: `npm run dev`. Витрина — http://localhost:5173/, редактор — http://localhost:5173/editor/.

В витрине и редакторе доступны лента, «Моя лента», блог, пост, коллекция, рейтинг, магазин, меню профиля и три модальных окна. Отсутствующие экраны ведут на локальную страницу.

Создайте копию темы кнопкой «+», переименуйте, настройте светлую и тёмную палитры. Изменения сохраняются в браузере. CSS содержит обе схемы и базовые серые токены; JSON можно импортировать для продолжения работы.

`npm run build` собирает статические файлы в `dist/`.

Оригинальные MHTML не меняются. Восстановление рабочих страниц (перезаписывает HTML): `python3 scripts/restore_html.py`, затем `python3 scripts/prepare_feed.py` и `python3 scripts/make_responsive.py`. Требуются Python и beautifulsoup4. Локальные фотографии в placeholders извлечены из архивов.

Коллекцию, «Мою ленту» и модальные окна можно повторно импортировать командой `python3 scripts/import_preview_screens.py collection.mhtml achievement.mhtml pro.mhtml gift.mhtml`. Передайте пути к четырём снимкам в этом порядке. Импорт обновляет только эти экраны и их локальные ресурсы.

Рейтинг и магазин импортируются командой `python3 scripts/import_catalog_screens.py rating.mhtml store.mhtml`. Магазин берёт содержимое из снимка DTF, а шапку и навигацию — из снимка vc.ru.

Оригинальный production JavaScript отключён. Это локальный просмотр сохранённых экранов, без серверных действий и авторизации. Несохранённые в MHTML шрифты заменяются системным шрифтом.

Для синхронизации палитр «Классика» и Contrast со стейджем сохраните скомпилированный CSS или снимок страницы MHTML и запустите `python3 scripts/sync_stage_tokens.py /path/to/snapshot.mhtml`. Проверьте изменения в `public/tokens.json`, `public/primitives.json` и `public/contrast.json`. Снимок стейджа нужен только на входе, рабочие HTML и исходные MHTML скрипт не перезаписывает.

## Витрина для продуктовой команды

Тема, режим и экран записываются в адрес, поэтому опубликованной ссылкой можно поделиться сразу с нужным видом.

Список опубликованных тем задаёт `showcase/themes.json`. «Классика» и Contrast используют текущие данные стейджа. Для своей темы экспортируйте готовую схему из редактора и добавьте в список запись с уникальным `id`, названием `name` и объектом `tokens` из экспорта под ключом `light` или `dark`. Если готовы обе версии, добавьте оба ключа в одну запись. После изменения списка снова запустите `npm run build`.

GitHub Pages публикует содержимое `dist/`. Главная открывает витрину, а путь `editor/` — редактор. Витрина не ссылается на этот путь. Доступ к редактору по прямому адресу открыт.
