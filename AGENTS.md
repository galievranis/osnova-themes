# Osnova Themes

Репозиторий содержит витрину «Оформление» vc.ru и DTF и Chrome-расширение Osnova Tokens для DTF-стейджа.

## Витрина и публикация

- Рабочая страница — `public/appearance.html`. Сохранять исходную разметку, классы, геометрию и адаптивность. Не подключать production JS и API. Использовать локальные ресурсы и ссылки. Заголовок вкладки начинается с `[PD]`.
- Палитры и паттерны сначала проверяем в витрине. Затем переносим их в расширение, дорабатываем на стейдже и отдаём разработчику CSS-экспорт.
- Проверять витрину на desktop и mobile с помощью `npm run dev`. Проверять обе схемы и загрузку локальных CSS и SVG. Перед публикацией запускать `npm run build -- --pages`.
- Пушим только по прямой просьбе пользователя. После пуша проверяем публикацию и наличие правок на GitHub Pages.

## Палитры тем в «Оформлении»

Для новых и обновляемых тем берём текущую «Классику» за основу. «Классика» и «Контраст» используют свои исходные палитры.

Меняем только значения существующих токенов из набора разработчиков. Сохраняем исходные имена и привязку компонентов к токенам. Для изменения цвета элемента сначала находим его исходный токен, затем задаём новое значение в палитре темы.

1. Задаём цвет шапки. Для градиента сохраняем сплошную заливку под ним и проверяем читаемость логотипа и иконок по всей ширине.
2. Задаём основной текст. Вторичный и третичный получаем смешиванием основного текста с заливкой острова в sRGB: 80% и 72% основного цвета в светлой схеме, 80% и 70% в тёмной. Для обычного текста проверяем контраст не ниже 4,5:1 с фонами, на которых он используется.
3. Задаём цвет основного фона страницы.
4. Задаём цвет или градиент фонового паттерна. Общий размер плитки 550 px, непрозрачность 10% в светлой схеме и 15% в тёмной.
5. Задаём акцент. Для hover и нажатия смешиваем его с чёрным на 8% и 14% в светлой схеме и с белым на 10% и 17% в тёмной. Вторичные, minimal и subtle-кнопки получают мягкие заливки из 5–16% акцента на цвете острова. Если заливка minimal отличается от «Классики», задаём существующему `--theme-color-round-button-background` то же значение. Проверяем контраст текста на акцентной заливке и видимость фокуса и состояний элементов управления.
6. В тёмной схеме остров получает 8% белого поверх цвета основного фона. В светлой схеме используем заливку острова из «Классики».

Контраст проверяем по фактическим цветам элементов в браузере в обеих схемах: обычный текст от 4,5:1, значимые иконки и индикаторы выбора от 3:1 к их непосредственной подложке. Отдельно проверяем точку радио, галочку и текст на акцентной заливке, границу невыбранного радио и иконку активного пункта навигации. Активный пункт навигации использует цвет острова, индикаторы на акценте используют контрастный цвет текста акцентной кнопки.

Разметку, размеры, отступы, границы, тени, статусные цвета и прочие токены берём из «Классики». Формулы оттенков для тем «Оформления» общие.
